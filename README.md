국회 의사중계 사이트에서 AI 자막을 실시간으로 수집하고, 회의 내용을 **TXT · SRT · VTT · JSON · MD · CSV** 형식으로 저장·내보내기 할 수 있는 Chrome 확장프로그램입니다.

## 지원 사이트

- `https://assembly.webcast.go.kr` (홈 및 플레이어)
- `https://webcast.assembly.go.kr` (홈 및 플레이어)

## 주요 기능

### 자막 실시간 수집
- 플레이어 페이지 진입 시 수집 자동 시작
- AI 자막 레이어 자동 활성화 시도
- 확정된 자막만 저장 — 인식 중·로딩 중 텍스트 자동 제외
- 자막 보정 시 제자리 갱신 (중복 없음)
- 본회의(전체 회의) 포함 모든 중계 유형 지원

### 페이지 내 우측 패널
- 국회 의사중계 페이지 오른쪽에 자동으로 표시
- **실시간 내용**: 현재 인식 중인 자막 미리보기
- **수집된 자막**: 확정된 자막 누적 목록
- 최근 N줄 복사, 중요 표시, 저장·내보내기 버튼

### 내보내기 형식

| 형식 | 특징 |
|------|------|
| TXT  | 텍스트 중심, 타임스탬프 포함 옵션 |
| SRT  | 동영상 자막 표준 (세션 시작 기준 상대 시간) |
| VTT  | 웹 자막 표준 (세션 시작 기준 상대 시간) |
| JSON | 세션 전체 복원 가능한 구조 |
| MD   | Markdown 표 형식 회의록 |
| CSV  | 스프레드시트 호환 표 형식 |

### 수집 기록 관리 (History)
- 저장된 회의 기록 목록 조회 및 전체 검색
- 즐겨찾기, 세션 메모 추가
- 기록 내 자막 검색 및 복사
- 항목 선택 기반 부분 복사 · 부분 내보내기
- 중요 표시만 내보내기, 시간 범위 지정 내보내기
- 전체 기록 JSON 백업 및 복원 (25 MiB 이하)
- 기록 삭제 (선택 삭제 / 전체 삭제)

### 자동 분할 저장 (Lineage)
긴 회의는 설정 임계값(기본: 2,000문장 / 120,000자 / 90분)을 넘으면 같은 회의 단위로 자동 분할 저장됩니다. History에서 연속 캡처 전체를 한번에 조회하거나 내보낼 수 있습니다.

### 자동 저장
- 수집 중 자동 주기 저장 (옵션에서 켜고 끄기 가능)
- 페이지 이탈·브라우저 종료 직전 최종 저장
- 재시작 후 미완료 저장 자동 복구

## 설치 방법

### Chrome 웹 스토어 (권장)
[Chrome 웹 스토어 → 국회 AI 자막 추출기](https://chromewebstore.google.com/detail/khchppfkjljacdhohihlpkbbkddmoghk) 에서 바로 설치할 수 있습니다. 설치 후 확장 아이콘을 툴바에 핀 고정하면 편리합니다.

### 직접 빌드하여 설치 (개발자용)

**사전 요구 사항**: Node.js 20 이상, npm

```bash
npm install
npm run build
```

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 활성화
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. `dist/` 폴더 선택
5. 브라우저 툴바에서 아이콘을 핀 고정

> 설치 전에 열려 있던 국회 탭은 새로고침해야 패널이 나타납니다.

## 사용 방법

### 1. 국회 의사중계 사이트 접속

`assembly.webcast.go.kr` 또는 `webcast.assembly.go.kr`의 플레이어 페이지로 이동합니다. 홈(`/main`) 페이지에서도 패널이 먼저 표시되지만, 실제 자막 수집은 플레이어(`/main/player*`) 페이지에서 시작됩니다.

### 2. 우측 패널 확인

페이지 오른쪽에 **국회 자막 도우미** 패널이 자동으로 나타납니다. 패널이 보이지 않으면 팝업의 **페이지 패널 열기**를 클릭하세요.

### 3. 자막 수집 시작

플레이어 페이지에 진입하면 수집이 자동으로 시작됩니다. AI 자막 레이어가 열리지 않으면 패널 안내에 따라 화면의 자막 버튼을 직접 클릭하세요.

### 4. 실시간 자막 확인

패널의 **수집된 자막** 목록에서 확정된 자막을 실시간으로 확인할 수 있습니다. 중요한 발언에 ★ 중요 표시를 달 수 있습니다.

### 5. 저장 및 내보내기

패널 또는 팝업의 버튼으로 원하는 형식(TXT · SRT · VTT · JSON · MD · CSV)으로 저장합니다. 확정된 자막만 저장 대상이며, 인식 중인 텍스트는 포함되지 않습니다.

### 6. 수집 중지

팝업에서 **멈추기**를 누르면 수집이 종료되고 자동으로 저장됩니다.

### 7. 기록 관리

팝업의 **저장된 기록**을 열어 History 페이지에서 과거 기록을 검색·복사·내보내기할 수 있습니다.

## 환경 설정

팝업의 **환경 설정**을 열어 아래 항목을 조정할 수 있습니다.

| 설정 | 설명 |
|------|------|
| 자동 저장 | 수집 중 주기 저장 켜기·끄기 |
| 자동 스크롤 | 패널 자동 스크롤 켜기·끄기 |
| 최근 N줄 복사 | 복사할 줄 수 |
| 저장 파일 이름 규칙 | `{date}` `{time}` `{committee}` 조합 |
| 노이즈 필터 | 기호·숫자만 있는 짧은 텍스트 자동 제외 |
| 중복 차단 최소 길이 | 반복 문장 차단 기준 글자 수 |
| 세그먼트 preset | 자동 분할 preset (안정성·균형·용량·사용자 지정) |
| 세그먼트 임계값 | 자동 분할 기준 문장 수·글자 수·시간 |

**수집 진단** 탭에서는 현재 수집 방식, 저장 복구 상태, 포맷별 예상 내보내기 크기를 확인할 수 있습니다.

## 권한

| 권한 | 사용 목적 |
|------|-----------|
| `storage` | 설정, 자막 기록, 즐겨찾기·메모 등 메타데이터 로컬 저장 |
| `downloads` | TXT · SRT · VTT · JSON · MD · CSV 파일 저장 |
| `offscreen` | 대용량 파일 Blob 처리 |
| `activeTab` | 현재 탭 상태 확인 |
| `scripting` | 기존 탭에 확장 재연결 |
| `sidePanel` | 브라우저 측면 보조 패널 (Chrome 114 이상) |
| 호스트 권한 | `assembly.webcast.go.kr`, `webcast.assembly.go.kr` 두 도메인만 |

모든 데이터는 사용자의 브라우저 내부에만 저장되며, 외부 서버로 전송하지 않습니다.

## 알려진 한계

- 국회 사이트 DOM 구조가 변경되면 자막 인식이 달라질 수 있습니다.
- Cross-origin 프레임 내부는 브라우저 보안 정책상 직접 접근이 제한될 수 있습니다.
- 브라우저 저장소 접근이 모두 실패하면 탭 종료 시 세션이 사라질 수 있습니다.
- 전체 기록 JSON 백업·복원은 25 MiB 이하 페이로드만 지원합니다.
- 노이즈 필터는 한글·영문 중심이며, 외국어 원문을 보존하려면 필터를 끄세요.
- 확장 설치 전에 열려 있던 탭은 새로고침이 필요할 수 있습니다.
